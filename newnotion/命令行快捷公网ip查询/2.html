命令行公网IP查询工具：api.ipify.org 与 ipinfo.io 完整使用指南 ​

一、两个API核心定位区分 ​

1. api.ipify.org：纯IP地址输出工具 ​

核心作用：只返回当前设备出口公网IP，无任何附加信息，极简轻量。

  • 输出格式：纯文本字符串，无JSON、无多余字段；
  • 无请求限制、无需鉴权，适合脚本自动化抓取IP；
  • 支持 -4（仅IPv4）、-6（仅IPv6）强制指定协议。

2. ipinfo.io：IP全维度归属地查询API ​

核心作用：输入IP后返回完整地理位置、运营商、时区、经纬度结构化信息，是IP溯源专用接口。

  • 默认返回JSON结构化数据，包含城市、国家、AS运营商、时区、坐标；
  • 支持两种用法：
    1. 直接访问 ipinfo.io：查询本机出口IP详情；
    2. ipinfo.io/xxx.xxx.xxx.xxx：查询任意指定IP的归属信息；
  • 支持路径筛选精简输出（如 ipinfo.io/city,org 只输出城市与运营商）。

二、基础命令实操示例（兼容bash/fish/zsh/macOS/Linux） ​

1. api.ipify.org 常用命令 ​

① 获取本机IPv4公网IP（你截图里的用法） ​

bash
# 强制使用IPv4链路获取出口IP
curl -4 https://api.ipify.org
# 输出示例：103.242.73.138

② 获取本机IPv6公网IP ​

bash
curl -6 https://api.ipify.org

③ 输出JSON格式IP（脚本解析更友好） ​

bash
curl https://api.ipify.org?format=json
# 返回 {"ip":"103.242.73.138"}

2. ipinfo.io 常用命令 ​

① 查询本机完整IP属地信息 ​

bash
curl ipinfo.io

输出完整JSON（对应你截图结构）：

json
{
  "ip": "103.242.73.138",
  "city": "Singapore",
  "region": "Singapore",
  "country": "SG",
  "loc": "1.2897,103.8501",
  "org": "AS41095 IPTP LTD",
  "postal": "018989",
  "timezone": "Asia/Singapore"
}

② 查询指定IP（截图示例） ​

bash
curl ipinfo.io/103.242.73.138

③ 精简输出，只提取城市、运营商（过滤多余字段） ​

bash
# 仅输出城市+运营商
curl ipinfo.io/city,org
# 针对指定IP精简查询
curl ipinfo.io/103.242.73.138/city,country,org

④ 使用jq格式化美化JSON输出（需提前安装jq） ​

bash
curl -s ipinfo.io | jq

三、两者典型使用场景划分 ​

场景1：自动化脚本获取本机出口IP → 优先用 api.ipify.org ​

适用场景：需要单纯拿到IP字符串做后续逻辑处理，不需要地理位置：

  1. 防火墙放行脚本：自动获取本机公网IP，写入服务器白名单；
  2. DDNS动态域名更新：定时抓取出口IP同步域名解析；
  3. 容器/虚拟机网络调试：快速确认宿主机出口公网地址；
  4. Shell变量赋值（纯文本无多余字符，不会解析出错）：
fish
# fish示例，把公网IP存入变量
set pub_ip (curl -4s https://api.ipify.org)
echo "当前出口IP: $pub_ip"

优势：返回纯文本，无JSON解析开销，脚本兼容性拉满，几乎不会出现格式解析报错。

场景2：IP溯源、排查网络线路归属 → 优先用 ipinfo.io ​

适用场景：需要判断IP地区、运营商，定位网络问题：

  1. 代理/隧道线路排查：判断当前出口节点是新加坡、香港还是国内； 如你截图结果：city:Singapore，可确认当前走新加坡节点；
  2. 服务器访问日志分析：查陌生来访IP的归属地，判断是否恶意扫描；
  3. 跨境服务故障排查：区分IP归属国家，定位访问延迟、封禁问题；
  4. 合规审计：记录请求IP对应的地区与运营商信息；
  5. 多线路切换验证：切换代理后执行命令，确认节点是否切换成功。

场景3：组合使用（最常用工作流） ​

先通过 api.ipify.org 抓取本机IP，再丢给 ipinfo.io 查归属，一条命令串联：

bash
# bash/fish通用组合查询
curl ipinfo.io/$(curl -4s https://api.ipify.org)

执行后一步获取「本机IP+完整属地运营商信息」，日常网络调试效率最高。

四、优缺点对比 ​

工具优点缺点
api.ipify.org1. 返回纯文本，脚本易处理
2. 请求极轻、响应快
3. 支持强制IPv4/IPv6
4. 无冗余字段		仅输出IP，无任何地理位置信息
ipinfo.io1. 全维度IP归属数据
2. 支持查询任意IP
3. 支持字段筛选精简输出
4. 结构化JSON便于解析		单纯获取IP时冗余信息多，脚本提取IP需额外解析

五、实用小技巧 ​

  1. fish一键别名，快速查节点
fish
# 一键输出本机IP+归属
function myip
    set ip (curl -4s https://api.ipify.org)
    echo "公网IP: $ip"
    curl ipinfo.io/$ip/city,org,country
end
funcsave myip

之后终端直接输入 myip 即可一键查看出口节点信息。

  1. 离线替代方案补充 无网络时两者均无法使用；运维离线查IP属地可使用 geoiplookup，但数据库更新滞后，精度远低于在线接口。

  2. 限流说明 两个接口均提供免费无密钥访问，日常个人调试、低频脚本不会触发限流；若高并发批量查询，建议申请ipinfo官方token提升限额。
