# 使用 `api.ipify.org` 和 `ipinfo.io` 获取 IP 及归属地信息

在日常开发和运维中，获取自己的公网 IP 以及查询某个 IP 的归属地信息，是非常高频的需求。`api.ipify.org` 和 `ipinfo.io` 是两个最常用的免费 API 工具，但它们的定位和使用场景完全不同。

## `api.ipify.org`：简洁的 IP 查询工具

`api.ipify.org` 是一个专注于一件事的 API：**返回你的公网 IP 地址**。

- **支持 IPv4 和 IPv6**：默认返回 IPv4，可通过 `?format=json` 获取 JSON 格式。
- **支持 HTTPS**：通过 `https://api.ipify.org` 访问，保证传输安全。
- **极简响应**：默认只返回纯文本的 IP 地址，适合脚本处理。
- **无请求限制**：个人项目无需注册即可免费使用。

### `api.ipify.org` 用法

```bash
# 返回纯文本 IPv4
curl api.ipify.org

# 返回 JSON 格式
curl api.ipify.org?format=json

# 返回 IPv6
curl -6 api.ipify.org
```

### `api.ipify.org` 适用场景

- **脚本中获取本机公网 IP**：如动态 DNS 更新脚本。
- **网络调试**：快速确认出口 IP 是否变化。
- **容器/服务器初始化**：获取当前节点的公网地址。

## `ipinfo.io`：丰富的 IP 情报查询工具

`ipinfo.io` 不仅返回 IP，还提供归属地、运营商、时区、地理位置等丰富信息。

- **免费版无需注册**：每天有约 50,000 次请求限制，个人使用绰绰有余。
- **支持查询任意 IP**：只需在 URL 后拼接 IP 地址。
- **返回结构化 JSON**：包含 `ip`、`city`、`region`、`country`、`loc`、`org`、`postal`、`timezone` 等字段。
- **支持批量查询**：可通过 `POST /batch` 接口一次性查询多个 IP。
- **提供 CLI 工具**：官方提供 `ipinfo-cli` 命令行客户端，方便高频使用。

### `ipinfo.io` 用法

```bash
# 查询本机 IP 归属地（JSON 格式）
curl ipinfo.io

# 查询任意 IP 归属地
curl ipinfo.io/103.242.73.138

# 只返回特定字段
curl ipinfo.io/103.242.73.138/city
```

### `ipinfo.io` 适用场景

- **日志分析**：追溯访问者来源地、运营商信息。
- **用户画像**：根据 IP 归属地为用户展示本地化内容。
- **网络安全**：初步判断访问 IP 是否来自异常地区。
- **运维监控**：了解出口 IP 的归属和网络链路信息。

## 两者对比总览

| 功能 | `api.ipify.org` | `ipinfo.io` |
| :--- | :--- | :--- |
| **响应内容** | 仅返回 IP 地址 | 返回完整归属地信息 |
| **查询任意 IP** | 不支持，只能查自己 | 支持 |
| **数据格式** | 纯文本或 JSON | 结构化 JSON |
| **请求限制** | 无（GCP 免费层） | 约 5 万次/天（免费版） |
| **适用场景** | 获取本机 IP | 查询 IP 归属地 |

## 真实场景：两者结合使用

在实际使用中，两者常常**配合使用**。

你刚才的执行过程正好体现了这种配合：

1. 用 `curl -4 https://api.ipify.org` 获取自己的公网 IP。
2. 拿到 IP 后，再用 `curl ipinfo.io/<IP>` 查询这个 IP 的归属地信息。

这种组合方式适合**需要同时知道“自己是谁”和“自己在哪”**的场景，比如在分布式系统的调试、代理出口检测、日志溯源等工作中非常实用。

## 注意事项

1. **仅公网 IP 可查**：内网 IP（如 `192.168.*.*`）在 `ipinfo.io` 上查不到归属地。
2. **IP 归属地的精度**：IP 地理信息通常是**城市级别**，无法精确到街道或具体建筑。
3. **数据可能有延迟**：IP 段重新分配后，归属数据库可能需要数周才能更新。

如果你的需求只是“想看看自己出口 IP 是多少，偶尔查查归属地”，这两个工具的组合方案已经足够稳定且免费。如果需要更频繁的批量查询，可以考虑 `ipinfo` 的付费方案或使用离线数据库（如 `nali`）。
